# SPIV Bot — ANIMA Project Notifier

Telegram-бот, який автоматично:
- 📋 Щопонеділка о 09:00 відправляє в чат задачі на тиждень з тегами відповідальних
- ⚠️ За 2 дні та за 1 день до зустрічі надсилає нагадування з агендою

---

## 🚀 Швидкий старт (Railway.app — безкоштовно)

### Крок 1 — Отримати Bot Token
1. Відкрий Telegram → знайди @BotFather
2. Напиши `/newbot` → дай ім'я → отримай токен вигляду `7123456789:AAHxxx...`

### Крок 2 — Знайти Chat ID групи
1. Додай бота до своєї групи
2. Додай @userinfobot до групи → він покаже Chat ID (число, починається з `-`)
3. Або напиши боту `/start` і відкрий: `https://api.telegram.org/bot<TOKEN>/getUpdates`

### Крок 3 — Деплой на Railway
1. Зареєструйся на [railway.app](https://railway.app) (GitHub логін)
2. New Project → Deploy from GitHub repo (або завантаж папку)
3. У Settings → Variables додай:

| Variable | Значення |
|---|---|
| `BOT_TOKEN` | твій токен від BotFather |
| `CHAT_ID` | ID чату (напр. `-1001234567890`) |
| `TG_MARY` | telegram username Mary (без @) |
| `TG_SERGE` | telegram username Serge (без @) |
| `TG_OLHA` | telegram username Olha (без @) |
| `TG_ANASTASIYAK` | telegram username AnastasiyaK (без @) |
| `TG_DIMA` | telegram username Dima (без @) |
| `TG_NASTYA_D` | telegram username NastyaD (без @) |
| `EXCEL_FILE` | `ANIMA_Gantt__1_.xlsx` |

4. Завантаж файл `ANIMA_Gantt__1_.xlsx` в корінь проєкту

### Крок 4 — Запуск
Railway автоматично запустить `worker: python bot.py` з Procfile.
